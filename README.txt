FILES
- index.html: page content and structure
- style.css: layout, colors, responsive styling
- script.js: mobile navigation, active nav, copyright year, email form
- images/profile-demo.svg: demo profile image

RUN LOCALLY
1. Extract the ZIP file.
2. Keep the folder structure intact.
3. Open index.html in a browser, or open the folder in VS Code and use Live Server.

REPLACE THE DEMO PHOTO
1. Copy your own photo into the images folder, e.g. images/sujal.jpg
2. Open index.html.
3. Find src="images/profile-demo.svg" and change it to src="images/sujal.jpg".
4. Save and refresh the browser. Use the exact file name and extension.
